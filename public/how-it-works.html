The workflow

How SIMOURA works

From a single smile photograph to an AI-assisted visualization.

  1. 01

    Upload

    Start with a clear smile photograph.

  2. 02

    AI Analysis

    Kimi analyzes visible smile characteristics such as alignment, crowding, tooth shade, smile arc, gum display and tooth proportions.

  3. 03

    Review

    Review visible observations and potential visualization directions.

  4. 04

    Visualize

    Generate an illustrative AI visualization using the original photograph as the visual reference.

  5. 05

    Precision Tooth Analysis

    For selected cases, SIMOURA can localize individually analyzable teeth using standard FDI numbering, verify the selected tooth, and create a focused visualization.
